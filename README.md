# 生鲜测试平台

一个用于生鲜产品测试的项目，包含测试用例、测试数据和测试报告。

## 项目结构

```
├── README.md          # 项目说明
├── test_cases/        # 测试用例目录
├── test_data/         # 测试数据目录
├── reports/           # 测试报告目录
└── scripts/           # 测试脚本目录
```

## 功能特性

- 生鲜产品质量检测
- 价格对比测试
- 库存管理测试
- 用户体验测试

## 技术栈

- Python
- pytest
- Selenium

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 运行测试
pytest
```
