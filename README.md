# 生鲜超市综合管理系统论文

## 📖 项目简介

本项目是一篇关于"基于SpringBoot的生鲜超市综合管理系统设计与实现"的毕业论文，详细阐述了生鲜超市管理系统的完整设计与实现过程。

## 📋 论文结构

### 主要章节

1. **绪论** - 研究背景、目的意义、国内外研究现状
2. **关键技术与可行性分析** - SpringBoot、MyBatis-Plus、Sa-Token、Vue3等核心技术介绍
3. **需求分析** - 业务需求、用户需求、功能需求、性能需求
4. **系统设计** - 架构设计、数据库设计、功能模块设计
5. **系统实现** - 各功能模块的具体实现
6. **系统测试** - 功能测试与性能测试
7. **总结与展望** - 项目总结与未来改进方向

## 🛠️ 技术栈

### 后端技术
- **框架**: SpringBoot 2.7.5
- **持久层**: MyBatis-Plus
- **数据库**: MySQL 8.0
- **缓存**: Redis
- **认证**: Sa-Token
- **支付**: 支付宝SDK
- **数据处理**: EasyExcel
- **Web容器**: Undertow

### 前端技术
- **框架**: Vue 3
- **构建工具**: Vite
- **UI组件**: Ant Design Vue 4
- **状态管理**: Pinia
- **可视化**: ECharts
- **路由**: Vue Router
- **HTTP客户端**: Axios

## 📊 核心功能模块

### 1. 用户与权限管理
- 用户注册与登录（Sa-Token认证）
- 个人信息管理
- 角色权限控制（管理员/普通用户）
- 验证码校验

### 2. 商品信息与分类管理
- 商品分类管理
- 商品信息管理（上下架）
- 商品搜索与分页
- 数据导入导出（EasyExcel）

### 3. 商品交易与支付管理
- 购物车管理
- 订单创建与状态管理
- 支付宝在线支付
- 余额支付
- 退款/换货审核

### 4. 库存管理与预警
- 入库信息管理
- 库存明细记录
- 库存预警机制
- 库存自动扣减

### 5. 会员与营销管理
- VIP会员管理
- 积分体系
- 优惠券管理
- 协同过滤商品推荐

### 6. 数据统计与可视化
- 销售数据统计
- ECharts可视化图表
- 数据导出功能
