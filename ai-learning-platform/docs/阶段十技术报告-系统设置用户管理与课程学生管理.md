## 二、AI 模型切换与总开关

### 2.1 配置更新

`backend/src/main/resources/application.yml`：

```yaml
spring:
  ai:
    openai:
      api-key: ${ZHIPU_API_KEY:7bcfccd6e77e416789ae78ae4ddcec23.7OSmeF0NkcaMOqZS}
      base-url: ${AI_BASE_URL:https://open.bigmodel.cn/api/paas/v4}
      chat:
        options:
          model: ${AI_MODEL:glm-4.7-flash}
```

密钥与模型均支持环境变量覆盖，代码中不硬编码。

### 2.2 AI 功能总开关

`ZhipuAiClient` 注入 `SystemConfigService`，所有 AI 调用（流式答疑 `chatStream` / 非流式出题批改 `chat`）统一经过 `checkAvailable()` 校验：

```java
private void checkAvailable() {
    if (!systemConfigService.isEnabled("ai_enabled")) {
        throw new BizException("AI 功能已被管理员关闭");
    }
    if (!isConfigured()) {
        throw new BizException("AI 服务未配置，请联系管理员");
    }
}
```

管理员在系统设置页关闭总开关后，学生端答疑、教师端出题/批改均**不发起任何模型调用**，直接返回降级提示。

### 2.3 运行时动态配置（系统设置热更新密钥/模型/端点）

`system_config` 表扩展三项 AI 接入配置，`ZhipuAiClient.resolveModel()` 在每次调用时读取生效配置，与缓存指纹（`apiKey|baseUrl|model` 拼接）比对，任一变化即重建模型客户端，**修改后即时生效、无需重启**：

```java
private OpenAiChatModel resolveModel() {
    String apiKey = effectiveApiKey();   // 系统设置优先，回退 yml 默认
    String baseUrl = systemConfigService.getValueOrDefault("ai_base_url", defaultBaseUrl);
    String model = systemConfigService.getValueOrDefault("ai_model", defaultModel);
    String fingerprint = apiKey + "|" + baseUrl + "|" + model;
    if (cachedModel == null || !fingerprint.equals(cachedFingerprint)) {
        // 重建 OpenAiApi + OpenAiChatModel 并刷新缓存
    }
    return cachedModel;
}
```

密钥安全处理：

- 回显：`SystemConfigService.list()` 对 `ai_api_key` 做**脱敏展示**（保留前 4 后 4 位，中间打码）；
- 保存：前端密钥输入框留空表示"不修改"；后端保存时空值直接跳过，避免脱敏值回写覆盖真实密钥。

出网代理兼容：模型客户端基于 Reactor Netty，启用 `proxyWithSystemProperties()`（仅当 JVM 设置了 `-Dhttps.proxyHost` 等参数时生效，直连环境不受影响），适配需要代理出网的部署环境。

### 2.4 限流与超时保护

- `429` 识别覆盖三层包装：原生 `RestClientResponseException`、WebClient 流式异常、Spring AI 包装的 `AiException`（消息形如 `429 - {...}`），任一命中均触发**最多 2 次指数退避重试**；
- 流式答疑超时 120s（免费模型高峰期首 token 可达 60s+）、非流式出题/批改超时 150s；
- 重试耗尽仍限流时提示"AI 服务限流，请稍后重试"。

### 2.5 实测结论

- 直连智谱 API 与经平台出题接口实测均成功（生成判断题 2 道、单选 2 道）；
- 学生端 AI 答疑流式问答端到端成功（45s 完整回复含代码示例）；
- 系统设置中修改模型为 `glm-4.7-flash` 后，后端日志确认配置热加载；
- `glm-4.7-flash` 为免费模型，高峰期存在间歇性 `429（code 1305 该模型当前访问量过大）`与响应变慢，已内置上述重试与超时保护，属外部服务容量问题，非集成缺陷。

## 三、管理端系统设置

### 3.1 数据库

新增 `system_config` 表（键值对 + 说明 + 更新时间，`config_key` 唯一）：

```sql
CREATE TABLE `system_config` (
  `id`           BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
  `config_key`   VARCHAR(50)  NOT NULL COMMENT '配置键',
  `config_value` VARCHAR(200) NOT NULL DEFAULT '' COMMENT '配置值',
  `remark`       VARCHAR(100) COMMENT '配置说明',
  `update_time`  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_config_key` (`config_key`)
) ENGINE = InnoDB COMMENT = '系统设置表';
```

初始配置项：

| config_key | 说明 | 默认值 |
|-----------|------|--------|
| `site_name` | 站点名称 | AI 辅助在线学习平台 |
| `ai_enabled` | AI 功能总开关（1 开启 0 关闭） | 1 |
| `register_enabled` | 开放学生自主注册（1 开启 0 关闭） | 1 |
| `ai_api_key` | AI 服务 API 密钥（留空使用后端默认配置） | ''（空） |
| `ai_model` | AI 模型名称（如 glm-4.7-flash） | ''（空） |
| `ai_base_url` | AI 服务端点（OpenAI 兼容） | ''（空） |

### 3.2 后端

- `SystemConfigService.list()` / `save(Map)`：仅管理员可操作（`UserContext.checkRole(ROLE_ADMIN)`）；保存时校验 key 白名单，逐项 upsert；空值跳过（支持"留空不修改"语义）；
- `list()` 对 `ai_api_key` 脱敏回显（保留前 4 后 4 位）；`getValueOrDefault(key, default)` 供 AI 客户端读取（系统设置优先，回退 yml 默认值）；
- `isEnabled(key)`：供各业务读取开关（默认开启，仅显式为 `0` 时关闭）；
- 接口：`GET /admin/ops/settings`、`POST /admin/ops/settings`（批量保存）。

### 3.3 注册开关联动

`AuthController.register` 在注册前检查 `register_enabled`，关闭时返回"平台已关闭自主注册，请联系管理员开通账号"——关闭自主注册后，账号统一由管理员在"用户管理"中创建。

### 3.4 管理端页面

`SystemSettingsView.vue`（路由 `/admin/settings`，菜单"系统设置"）：

- **基础设置**：站点名称输入框 + 注册开关（带状态说明文案）；
- **AI 功能设置**：AI 总开关；**模型接入**区块——API 密钥（密码框，留空不修改，placeholder 显示当前脱敏密钥）、模型名称（自动完成，内置 glm-4.7-flash / glm-4.6-flash / glm-4.5-flash 等建议项，可自由输入）、服务端点 Base URL（OpenAI 兼容，留空用后端默认）；
- 保存后 AI 配置即时生效，无需重启后端。

## 四、用户管理扩展

### 4.1 后端接口

`AdminOpsController` 新增：

| 接口 | 说明 |
|------|------|
| `POST /admin/ops/users` | 新增用户（指定学生/教师/管理员角色 + 初始密码） |
| `PUT /admin/ops/users/{userId}` | 编辑用户（昵称/角色/状态） |
| `DELETE /admin/ops/users/{userId}` | 删除用户（级联清理业务数据） |
| `POST /admin/ops/users/{userId}/reset-password` | 重置密码 |

### 4.2 业务规则

- **新增**：用户名唯一校验；密码 BCrypt 加密；角色限定学生(1)/教师(2)/管理员(3)；初始积分账户同步创建；
- **编辑**：用户名不可修改；角色可调整；
- **重置密码**：新密码 BCrypt 加密后覆盖，旧密码立即失效；
- **删除**：不允许删除自己（`admin` 删除自己会导致平台无管理员）；事务内级联清理该用户的 AI 会话与消息、选课、学习记录、笔记、考试答题/考试记录/练习记录、积分账户/流水/签到/活动/优惠券、课程评论，最后删除用户本体，避免孤儿数据。

### 4.3 管理端页面（二级路由分类 + 手机端适配）

按"二级路由为分类、三级路由为功能界面"的结构改造：侧边栏"用户管理"为分组菜单，展开后三个子项分别对应三个三级路由页，共用 `UserList.vue` 组件（`role` prop 区分角色）：

| 路由 | 页面 | 角色 |
|------|------|------|
| `/admin/user/student` | 学生管理 | 学生（23 个账号） |
| `/admin/user/teacher` | 教师管理 | 教师 |
| `/admin/user/manager` | 管理员账号 | 管理员 |

`UserList.vue` 功能与适配：

- 工具栏：关键字搜索（用户名/昵称）+ 状态筛选 + 新增用户按钮；
- 行操作：编辑（弹窗回填，用户名不可改）、重置密码（弹窗输入新密码）、禁用/启用、删除（二次确认）；当前登录账号显示"当前账号"标识，不提供操作；
- **桌面端**（>768px）：表格布局，操作列固定右侧；
- **手机端**（≤768px）：卡片列表布局——头像 + 昵称/用户名 + 状态徽标 + 注册时间 + 块状操作按钮 + 简洁分页器；弹窗宽度自适应（92%）；
- 通过 `window.innerWidth` + `resize` 监听动态切换布局（onUnmounted 时移除监听）。

## 五、课程学生管理

### 5.1 权限模型

| 角色 | 可见课程 | 可执行操作 |
|------|---------|-----------|
| 教师 | 仅自己创建的课程 | 查看学生分页 / 添加学生 / 查看学习详情（小节完成明细）/ 移除学生 |
| 管理员 | 全部教师创建的课程 | 同教师（可跨教师操作任意课程） |
| 学生 | 无权限 | 接口直接 403 |

`checkCourseAccess()` 统一鉴权：教师访问他人课程返回 `403 只能管理自己创建的课程`。

### 5.2 后端接口

`CourseStudentController`（`/course/{courseId}/students`）：

| 接口 | 说明 |
|------|------|
| `GET ?page=&size=&keyword=` | 课程学生分页（含学生信息、账号状态、学习进度、选课时间），支持用户名/昵称关键字过滤 |
| `GET /candidates?keyword=` | 可添加学生候选（未选本课的启用状态学生，最多 50 条） |
| `POST` | 添加学生（按 `studentId` 或 `username`；仅学生角色；已在课幂等返回） |
| `GET /{studentId}/progress` | **学习详情**：该学生在本课程各章节下每个小节的完成状态（视频/图文类型、时长、完成标记、最近学习时间），按章节分组并含 x/y 小节统计 |
| `DELETE /{enrollmentId}` | 移除学生（删除选课记录，学习记录保留但不再计入课程） |

> 按需求调整：移除原"进度调整"接口（`PUT /{enrollmentId}`），改为教师/管理员查看学生小节完成明细的只读学习详情。

### 5.3 管理端页面

新建共用页面 `CourseStudentsView.vue`：

- **教师端**：菜单"教学管理 → 学生管理"（路由 `/teacher/course/students`），课程下拉仅显示自己的课程；
- **管理员端**：菜单"课程管理 → 学生管理"（路由 `/admin/course/students`），课程下拉显示全部课程，页面附权限说明提示条；
- 功能：课程选择 → 学生分页表格（头像/昵称/账号状态/进度条/选课时间）→ 添加学生弹窗（"从候选学生选择"支持搜索、"按用户名添加"双模式）→ **学习详情抽屉** → 移除二次确认；
- **学习详情抽屉**：按章节折叠面板展示——章节标题 + "x/y 小节"完成度标签；小节行含类型图标（视频/图文）、标题、时长、完成状态（绿色对勾 + 最近学习时间 / 灰色"未完成"）；手机端抽屉全屏（100% 宽）、桌面端 520px。
