# 项目结构模板（企业化 Monorepo 布局）

> 新项目初始化时按此模板创建目录。单一仓库管理全部工程，便于统一版本、统一同步。

## 一、顶层结构

```
<project>/
├── backend/                # Spring Boot 后端（见 二）
├── admin-web/              # 管理端（Vue3 + Ant Design Vue，端口 5174）
├── student-web/            # 用户端（Vue3 + Naive UI，端口 5173）
├── docs/                   # 阶段技术报告 + 设计文档（见 四）
├── prototype/              # HTML 静态原型（可选，前期设计确认用）
├── tests/                  # 接口测试脚本（Python requests）
├── sql/                    # 独立 SQL 资产（可选；正式建表语句在 backend/sql/）
└── sync.sh                 # 仓库同步脚本（rsync + git push）
```

## 二、backend 工程结构

```
backend/
├── pom.xml                 # Spring Boot 3 + mybatis-plus + sa-token + spring-ai
├── sql/
│   ├── init.sql            # 建表 + 初始配置数据（权威版本）
│   ├── demo_data.sql       # 演示数据（可选）
│   └── gen_*.py            # 演示数据生成脚本（可选）
└── src/main/
    ├── java/com/<org>/<project>/
    │   ├── <Project>Application.java
    │   ├── common/                     # Result / BizException / GlobalExceptionHandler
    │   │                               # UserContext / FileUploadController
    │   ├── config/                     # SaTokenConfig / CorsConfig / MybatisPlusConfig
    │   │                               # WebResourceConfig / 过滤器
    │   └── module/<domain>/             # 业务模块（垂直切分）
    │       ├── controller/             # AdminXxx / TeacherXxx / StudentXxx
    │       ├── service/
    │       ├── mapper/
    │       ├── entity/
    │       └── dto/                    # VO / 入参 DTO
    └── resources/
        ├── application.yml              # 环境变量占位符：${KEY:默认值}
        └── mapper/                      # （如有 XML）
```

## 三、前端工程结构（以管理端为例）

```
admin-web/
├── vite.config.js          # 端口 5174 + /api 代理到 8080
├── package.json
└── src/
    ├── main.js
    ├── App.vue
    ├── api/                # 按后端模块分文件：ops.js / course.js / exam.js / ai.js / points.js
    ├── assets/
    ├── components/         # 跨页面复用组件（如 UserList.vue、ExchangeModal.vue）
    ├── layouts/
    │   ├── MainLayout.vue  # 侧边栏 + 顶栏 + 内容区；菜单含分组子菜单
    │   └── RouteGroup.vue  # 二级分类容器（子路由出口）
    ├── router/index.js     # 集中路由表；守卫控制登录
    ├── stores/user.js      # Pinia 登录态
    ├── utils/request.js    # axios 封装（见前端规范）
    └── views/
        ├── login/
        ├── dashboard/
        ├── profile/
        ├── admin/          # 仅管理员可见页面（可再嵌套子目录分组）
        │   └── user/       # 同类多页共用组件：UserList.vue + 三个薄壳视图
        ├── teacher/         # 教师功能页（课程/考试/AI 出题批改）
        └── course/          # 跨角色页面（按课程维度）
```

## 四、docs 目录约定

```
docs/
├── 项目设计文档.md          # 总体设计（架构/ER/权限矩阵）
├── 开发计划书.md            # 阶段规划
└── 阶段N技术报告-<主题>.md   # 每阶段一份（结构见 01-开发流程.md 第四节）
```

命名固定格式：`阶段<中文数字>技术报告-<主题>.md`，与开发推进一一对应。

## 五、基础设施清单（初始化即建）

| 组件 | 落点 | 说明 |
|------|------|------|
| 统一响应 | `common/Result.java` | `{code, message, data}`，code 200 成功 / 401 未登录 / 500 业务失败 |
| 业务异常 | `common/BizException.java` + `GlobalExceptionHandler` | message 直接面向用户 |
| 用户上下文 | `common/UserContext.java` | ThreadLocal：userId / role / checkRole |
| 登录鉴权 | `config/SaTokenConfig.java` | 拦截 `/**`，放行登录/注册/健康检查/静态资源 |
| 文件上传 | `common/FileUploadController.java` | UUID 重命名 + 白名单扩展校验 |
| 分页插件 | `config/MybatisPlusConfig.java` | PaginationInnerInterceptor |
| 跨域/代理 | `config/CorsConfig.java` + vite proxy | 前端只走相对路径 `/api` |
| 仓库同步 | 根目录 `sync.sh` | rsync 排除构建产物 + 条件 commit + push |

## 六、端口与命名约定

| 项 | 约定 |
|----|------|
| 后端 | 8080，context 随意（前端统一 `/api` 前缀） |
| 管理端 | 5174 |
| 用户端 | 5173 |
| 数据库 | MySQL 8，库名 snake_case 全小写 |
| 表名/字段 | snake_case，表每字段带 COMMENT |
| Java 包 | `com.<org>.<project>` 全小写 |
| 组件文件 | PascalCase（`UserList.vue`）；视图 `XxxView.vue` |
| Git | main 单分支；commit 格式 `自动更新：同步项目代码与文档 <时间>` 或 `feat/fix: <描述>` |
