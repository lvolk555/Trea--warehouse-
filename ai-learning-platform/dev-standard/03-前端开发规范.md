# 前端开发规范（Vue 3 + Vite 双端应用）

## 一、工程组织

一个项目两（多）个独立前端工程，**技术栈按用户群区分**：

| 端 | 技术栈 | 端口 | 说明 |
|----|--------|------|------|
| 管理端 | Vue3 + Vite + **Ant Design Vue** + Pinia + vue-router | 5174 | admin / teacher 登录使用 |
| 用户端 | Vue3 + Vite + **Naive UI** + Pinia + vue-router | 5173 | 终端用户使用 |

每个工程内部结构：

```
src/
├── api/          # 按后端模块分文件的接口封装（ops.js / course.js / ai.js…）
├── views/        # 页面，目录按"角色/功能域"两级组织
├── components/   # 跨页面复用组件（如列表选择、兑换弹窗）
├── layouts/      # 主布局 + 分组路由布局（RouteGroup.vue）
├── router/       # 集中式路由表
├── stores/       # Pinia（用户信息/登录态）
└── utils/        # request.js（axios 封装）等
```

## 二、axios 统一封装（request.js）

```js
const request = axios.create({
  baseURL: '/api',
  timeout: 15000,
  // 参数二次编码：兼容反向代理对 query string 预解码一次的行为
  // （配合后端 QueryParamDecodeFilter 容错解码，直连/代理行为一致）
  paramsSerializer: {
    serialize: (params) => {
      const parts = []
      Object.keys(params || {}).forEach((key) => {
        const value = params[key]
        if (value === undefined || value === null || value === '') return
        parts.push(`${encodeURIComponent(key)}=${encodeURIComponent(String(value)).replace(/%/g, '%25')}`)
      })
      return parts.join('&')
    }
  }
})

// 请求拦截：附加 token（Sa-Token，Bearer 前缀）
request.interceptors.request.use((config) => {
  const token = localStorage.getItem('<端>_token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 响应拦截：解包 {code, message, data}；401 自动登出
request.interceptors.response.use(
  (res) => {
    const body = res.data
    if (body.code === 200) return body.data      // 页面直接拿 data
    if (body.code === 401) { useUserStore().logout() }
    return Promise.reject(new Error(body.message || '请求失败'))
  },
  (err) => Promise.reject(err)
)
```

API 封装纪律：
- 接口函数按后端模块分文件，命名动宾结构：`userPage` / `createUser` / `resetUserPassword`；
- 页面里**永远不直接写 axios**，统一走封装实例；
- token 存 localStorage，键名按端前缀隔离（`admin_token` / `student_token`）。

## 三、路由与菜单规范

### 3.1 路由分级

**一级布局 → 二级分类 → 三级功能页**：

```js
// 用户管理（二级分组路由：角色分类 → 三级功能页）
{
  path: 'admin/user',
  component: () => import('../layouts/RouteGroup.vue'),
  children: [
    { path: 'student', name: 'user-student', component: () => import('../views/admin/user/UserStudentView.vue') },
    { path: 'teacher', name: 'user-teacher', component: () => import('../views/admin/user/UserTeacherView.vue') },
    { path: 'manager', name: 'user-manager', component: () => import('../views/admin/user/UserManagerAccountView.vue') },
    { path: '', redirect: { name: 'user-student' } }
  ]
}
```

- 同类多功能（如按角色管用户）用**分组菜单 + 三级路由页**，侧边栏体现为可展开分组；
- 菜单 key 与路由 name 保持一致，便于权限过滤（`developedRoutes` 白名单控制菜单可见性）。

### 3.2 页面复用

同一套 UI 逻辑不同数据源时，抽**参数化共用组件**：

```vue
<!-- UserList.vue 接收 role prop，三个视图页各自传角色 -->
<UserList :role="1" title="学生管理" />
```

## 四、移动端适配（强制）

所有列表/管理页面必须双布局：

```vue
<script setup>
// 断点：<=768px 视为移动端
const isMobile = ref(false)
function checkWidth() { isMobile.value = window.innerWidth <= 768 }
onMounted(() => { checkWidth(); window.addEventListener('resize', checkWidth) })
onUnmounted(() => window.removeEventListener('resize', checkWidth))
</script>

<template>
  <a-table v-if="!isMobile" ... />        <!-- 桌面：表格 -->
  <div v-else class="mobile-list">...</div> <!-- 移动：卡片列表 -->
</template>
```

移动端要点：
- 卡片：头像 + 主标题（昵称）+ 副标题（用户名）+ 状态徽标 + 元信息 + **块状操作按钮**（grid 布局）；
- 弹窗/抽屉宽度自适应：`:width="isMobile ? '92%' : 520"`，抽屉移动端 `100%` 全屏；
- 工具栏输入框 `flex: 1` 填满；
- **注意**：模板里不要直接访问 `window`（用 isMobile 响应式变量，避免 SSR/渲染警告）。

## 五、UI 准则

1. **不显示技术标识**：
   - 列表/标签/详情一律展示名称（昵称优先，回退用户名），不展示数据库 ID；
   - 筛选输入框是"按学生名称/用户名搜索"的**文本框**，不是"按 ID 筛选"的数字框；
   - 需要后端提供名称字段时就加 VO 字段，不在前端猜。
2. **危险操作二次确认**：删除/移除用 `Modal.confirm`，文案说明后果（"其选课、学习、考试、积分等数据将一并清除，不可恢复"）；
3. **当前账号保护**：自己那行显示"当前账号"标识且不提供编辑/删除按钮；
4. **列表标配**：加载态（spin）、空态（empty）、分页（pageSize 10 + 总数展示）；
5. **反馈即时**：成功 `message.success`、失败 `message.error(e.message)`（后端 BizException 的友好文案直达用户）。

## 六、状态管理与登录流

- Pinia user store：token、用户信息、logout（清 token + 跳登录页）；
- 登录页按端区分入口（管理端 / 用户端），错误提示展示后端 message；
- 路由守卫：未登录跳登录页（按端各自的登录路由）。

## 七、Vite 配置

```js
export default defineConfig({
  plugins: [vue()],
  server: {
    port: 5174,                      // 各端固定端口
    proxy: { '/api': { target: 'http://localhost:8080', changeOrigin: true } }
  }
})
```

- 前端只请求相对路径 `/api/**`，由 Vite 代理转发后端，避免跨域与硬编码地址。
