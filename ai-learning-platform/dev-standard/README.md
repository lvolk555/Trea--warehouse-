# 全栈项目开发规范与流程（dev-standard）

> 提炼自 AI 辅助在线学习平台的完整开发实践（阶段一 ~ 阶段十）。
> 适用于 Spring Boot + Vue3 前后端分离项目的从零搭建到交付全流程。
> 新项目可直接按本目录文档执行；配合 TRAE 使用时加载 [SKILL.md](./SKILL.md)。

## 核心理念（一分钟版）

1. **阶段化交付**：大需求拆成阶段（每阶段 1~3 个主题），每阶段产出可运行版本 + 技术报告；
2. **测试先行收口**：功能完成 ≠ 完成，接口测试 + 浏览器测试 + 回归测试全部通过才算完成；
3. **文档即代码**：每阶段的技术报告含要点拆解表、实现方案、接口清单、测试结果、文件清单，归档进 `docs/`；
4. **界面无技术标识**：前端一律展示名称（昵称优先），不暴露 ID；搜索按名称而非 ID；
5. **移动端一等公民**：所有管理页面 768px 断点双布局（桌面表格 / 移动卡片）；
6. **安全内建**：敏感配置脱敏回显、密钥留空不改、删除二次确认、级联清理孤儿数据；
7. **持续同步**：sync.sh 一键 rsync + commit + push，可配定时任务自动同步。

## 快速开始（新项目）

```bash
# 1. 按 04-项目结构模板.md 初始化目录
# 2. 复制 sync.sh，替换 REPO 路径与项目子目录名
# 3. 按 02/03 规范开发，按 01 流程推进阶段
# 4. 每阶段结束：测试 → 写技术报告 → bash sync.sh
```
