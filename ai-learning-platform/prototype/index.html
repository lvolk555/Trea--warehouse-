关于 Java 中的多态，下列说法正确的是？
A多态是指一个类只能有一个父类
B方法重写是实现多态的基础，父类引用可以指向子类对象
C静态方法可以被重写从而实现多态
Dprivate 修饰的方法可以被子类重写
✅ 回答正确！
解析：多态的三个必要条件是继承、方法重写、父类引用指向子类对象。静态方法与私有方法不能被重写，A 描述的是单继承而非多态。

老师，什么是 IoC 和 DI？它们在 Spring Boot 里怎么用？
AI
IoC（控制反转）是一种设计思想：对象的创建和依赖管理不再由你自己 new，而是交给 Spring 容器。

DI（依赖注入）是 IoC 的实现方式，容器自动把依赖"注入"到你的类中。

在 Spring Boot 中，用 @Service 标注业务类，用 @Autowired 注入依赖即可：

@Service public class UserService {...}

这样你就不需要手动 new UserService() 了。还有疑问可以继续问我～
